# 🏢 CRUD de Moradores - Frontend

Este é o frontend do sistema de gerenciamento de moradores de um condomínio. A aplicação consome uma API REST desenvolvida em Spring Boot, permitindo listar, criar, editar e remover moradores.

---

## 🚀 Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Fetch API 

---

## 📌 Funcionalidades

- Listagem de moradores
- Visualização de dados 
- Edição de moradores
- Estrutura preparada para criação e exclusão
- Integração com API backend em Spring Boot
